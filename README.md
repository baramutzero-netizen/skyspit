# 앙천이타 (仰天而唾)

누워서 하늘을 향해 침을 뱉는 도트 인크리멘탈 게임입니다.
뱉을 때마다 속이 후련해지지만, 위로 뱉은 건 언젠가 전부 내 얼굴로 돌아옵니다.

**바로 플레이:** https://baramutzero-netizen.github.io/skyspit/

`index.html` 한 파일로 돌아가서, 내려받아 브라우저로 열어도 됩니다(그림·소리·글꼴이 모두 한 파일에 들어 있음).

## 하는 법

- 현장 탭에서 "퉤! 뱉기"(또는 장면, 스페이스바)를 누르면 위로 뱉고 **후련함**이 쌓입니다.
- 뱉은 건 **체공 시간**이 지나면 얼굴로 돌아옵니다. 위의 판에는 지금 하늘에 떠 있는 개수와 돌아온 개수가 나옵니다.
- 악행도 탭의 노드 트리에서 후련함으로 수를 삽니다. 독설은 후련함을 키우고 체공 시간도 늘립니다. 당장은 덜 돌아오는 것 같지만, 하늘에 떠 있는 양은 계속 불어납니다.
- 아직 가지 않은 장소의 노드는 `?`로 가려집니다. 모든 수를 갖춘 뒤 **일어나기**를 사면 엔딩이 나옵니다. 한 판은 5분 남짓입니다.

## 담긴 것

- **장소 7곳:** 자취방 → 회사 단톡방 → 댓글창 → 방송국 → 토론회 → SNS → AI 공장
- **뱉는 것:** 침 → 뒷담화 → 악플 → 지라시 → 막말 → 가짜뉴스 → AI 슬롭
- **수 75개:** 캡처 금지 공지, 닉네임 갑옷, 어그로 제목, [단독] 말머리, 관계자에 따르면, 악마의 편집, 너는 뭐 잘했냐, 앞뒤 자르기, 유감 표명, 알고리즘, 퍼가요, 그리고 프롬프트 한 줄로 AI 뉴스·게시글·댓글·그림·드라마·게임을 찍어 내고, 병렬 에이전트와 AI 코딩으로 무차별 양산…
- **구경꾼:** 룸메이트, 팀 동료, 키보드 워리어, 연예부 기자, 열성 지지자, 봇 계정, AI 시청자까지(모두 지어낸 인물이며 특정 인물·단체와 관계없음)
- **악단:** 장소마다 두 파트(코골이 베이스·손가락 드럼, 키보드·알림음, 타자 비트·좋아요, 예능 효과음·방청객 웃음, 하울링·발언 시간 비트, 숏폼 비트·보이스 칩, GPU 팬 소음·합성 음성 합창)
- **엔딩:** 일어나기 — 일어나 보니 세상엔 AI만 남았고, 하늘에 떠 있던 말이 전부 나에게로 내려옵니다
- **뒷정리 보고서:** 결과 카드 PNG 저장·공유, 다른 게임 추천

## 폴더

| 경로 | 내용 |
| --- | --- |
| `index.html` | 완성된 게임 한 파일 |
| `game.src.html` | 게임 소스 (글꼴·그림 자리 표시자 포함) |
| `assets/aseprite/` | 도트 원본 `.aseprite` (`audience.aseprite`는 구경꾼 종류별 프레임, `spit.aseprite`는 장소별 침 색) |
| `assets/png/` | 같은 그림 4배 PNG |
| `tools/sprites.py` | 모든 도트의 원본 데이터 → `sprites.json`, `.aseprite`, PNG 생성 |
| `tools/build.py` | 글꼴을 쓰는 글자만 잘라 넣고 `index.html`을 만듦 |

## 다시 빌드하기

Python 3와 갈무리 글꼴(`npm pack galmuri`)이 필요합니다.

```bash
pip install pillow fonttools brotli
cd tools && python3 sprites.py && cd ..
GALMURI=경로/package/dist python3 tools/build.py
```

## 만든 것과 빌린 것

- 도트 그림과 소리는 모두 직접 그리고 합성했습니다(소리는 브라우저에서 실시간 합성).
- 글꼴: [갈무리(Galmuri)](https://github.com/quiple/galmuri) © Lee Minseo, SIL Open Font License 1.1 — 게임에 쓰는 글자만 잘라 넣었습니다. 라이선스 전문은 `fonts/Galmuri-OFL.txt`.
- 진행 기록은 브라우저(localStorage)에만 저장되고 어디에도 보내지 않습니다.
